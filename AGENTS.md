# HH Assistant: инструкции агенту

Общайся с пользователем по-русски. Выполняй одну небольшую задачу за раз.
Перед изменениями прочитай README.md и относящиеся к задаче исходники.
Проверь `git status --short`; сохраняй чужие и незакоммиченные изменения.

## Карта проекта

- main.py — поиск вакансий; desktop_ui.py — tkinter; browser_queue.py — очередь ссылок.
- llm_client.py — транспорт LM Studio и управление моделями.
- evidence_eval.py и vacancy_rules.py — доказательства и правила оценки.
- settings.py и storage.py — настройки, cookies, история и кэш.
- resume_tailor.py — PDF-черновики резюме.
- tests/ — unittest; examples/ — обезличенные образцы.
- local-agent/ — подготовка запасного локального помощника программиста.

## Работа

Не меняй правила карьерного профиля, зарплаты и вердиктов без явной задачи.
Не запускай поиск вакансий, GUI и переключение моделей для проверки кода.
LM Studio может быть занят HH Assistant: не выгружай активную модель автоматически.
Для проверки используй `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`
из корня проекта; сначала можно запустить относящийся к изменению тестовый файл.
Если .venv отсутствует, сообщи об этом; не устанавливай зависимости молча.
Показывай результат: что изменил, какие проверки выполнил, что осталось непроверенным.
Не утверждай, что проверка прошла, если её не запускал.

## Данные

Не читай config.json, profile.txt, resume_data.json, cookies, фото, cache/ и results/
без необходимости для конкретной задачи. Для примеров используй examples/.
Не добавляй личные данные в Git, запросы удалённым моделям или отчёты.
Не делай push, commit, удаление данных и установку пакетов без явной задачи пользователя.

Это инструкции для модели, а не техническая изоляция. Ограничения доступа
и подтверждения команд настраиваются отдельно в Harness.
