# Изменения

## 2026-10-02 — поездки и группы объявлений

- Добавлены формы стажа «2х лет», «работали ассистентом» и раздел «Вы нам подойдёте».
- Явный разъездной характер работы является ограничением, даже без числа поездок.
  Редкие командировки не приравниваются к регулярным.
- Почти одинаковые объявления с совпадающими названием, работодателем и вердиктом
  объединяются в отображении; оригинальные оценки, ссылки и различия сохранены.
- В карточке группы можно отдельно открыть каждый вариант; массовое открытие
  сохраняет все ссылки, чтобы не скрыть различающиеся условия.
- Версия оценок повышена до v6.


## 2026-10-02

- Рабочие навыки подтверждаются конкретным умением, без обязательного наличия
  слов «уверенно» или «свободно». Базовые и экспертные требования различаются.
- Требование опыта перед списком должностей сохраняется вместе с первой строкой списка.
- Явная экспертная поддержка в обязанностях требует проверки навыков, даже если
  модель выбрала другую строку с базовыми знаниями.
- Версия оценок повышена до v5.


## 2026-10-01 — контекст требований

- Пункты опыта проверяются вместе с разделом, включая границы необязательных
  требований; стаж компании и преимущества работодателя не считаются стажем кандидата.
- Распознаётся срок профильной деятельности, даже без названия должности.
- Рабочие навыки отделены от экспертности; соответствие навыкам кандидата
  показывается как отдельное уточнение.
- IT-функция восстанавливается по техническим обязанностям, а не отрасли компании.
- Наличие собственной IT-системы и слово «работать» не подтверждают техподдержку.
- Версия проверки повышена до v4.


## 2026-10-01 — исправления после контрольного прогона

- Заголовок «Наши пожелания» больше не отменяет явное требование профильного стажа;
  «Будет плюсом» и явно желательный опыт остаются необязательными.
- Распознаётся опыт консультантом и специалистом поддержки без указанного числа лет.
- Уровень Middle/Senior у команды не переносится на кандидата.
- Уточнены проверки MedTech, разработки digital-решений и проектной координации.
- Знакомство с BPMN-движком не считается основной работой по моделированию.
- Ошибочное заявление о допуске без опыта исправляется на владение инструментами
  только при наличии явной строки об этих инструментах; профильный стаж имеет приоритет.
- Повторное извлечение получает предыдущий ответ для исправления ошибочных полей.
- Версия правил обновлена: старые решения не блокируют переоценку.

## 2026-10-01

- Поиск сначала собирает названия со всех выбранных страниц, затем оценивает
  полные описания. Очередь исключает повторы между источниками.
- Быстрый отсев получает только названия; близкие профессии защищены от
  исключения моделью, тег опыта HH не передаётся.
- Неизвестные зарплата и оформление показываются как вопросы к работодателю,
  не скрывая вакансию с подходящими задачами. Подтверждённые запреты сохранены.
- Проверка опыта учитывает разделы требований и пожеланий, а также английские
  формулировки. Противоречивый допуск без опыта требует уточнения.
- Неподтверждённые поля повторно проверяются моделью один раз. Сохранены обе
  попытки и итоговые цитаты для аудита.
- Для локального LM Studio добавлена последовательная загрузка настроенной
  пары моделей через CLI. Неизвестная модель больше не заменяется первой доступной.
- Контекст и reasoning настраиваются отдельно и входят в версию кэша.
  Аудит сохраняет доступную статистику токенов последнего запроса.
- Новая версия правил отделяет решения следующего прогона от старых.

## 2026-09-30

- Оценщик извлекает факты по JSON-схеме и ссылается на строки первоисточника.
  Цитаты подставляются и проверяются программно; решение принимается отдельно.
- Добавлен REVIEW «Нужно уточнить», отделённый от подходящих и массового открытия.
- Полные описания и доказательства решений сохраняются локально для аудита.

- По уточнённому выбору пользователя обязательный коммерческий опыт или
  стаж в аналогичной должности снова исключают вакансию; желательный опыт,
  явный допуск новичков и один тег HH не являются причиной отказа.
- Целевые запросы HH выполняются перед широкими категориями.

- Явный Middle/Senior в названии или формулировке уровня в описании
  проверяется отдельно от допустимого дефицита опыта на начальных ролях.
  Уточнены приоритет отказа по уровню/IT-контексту и оценка WEAK при дефиците опыта.

- Убраны безусловные программные отказы по QA и числу лет опыта: оценка
  учитывает актуальный профиль, задачи и дефицит навыков. Для начальных задач
  с требованием опыта предусмотрен WEAK, а не автоматический отказ.
- Уточнена обработка неизвестных условий, редких поездок и запасных направлений.
  Добавлена проверка явно указанной месячной зарплаты на руки ниже 40 000 ₽.

## 2026-09-28

- Открытие вакансий останавливается после каждой пачки из 50 ссылок и ждёт
  ручного продолжения. Интервал 20 секунд сохранён. Ручная пауза сохраняет позицию.
- Ссылки HH на один ID с разными поддоменами или метками перехода объединяются
  перед открытием. Разные объявления не скрываются по совпадению названий.

## 2026-09-27

- После остановки поиска подходящие вакансии текущего прогона можно открыть
  в браузере по умолчанию с паузой 20 секунд. Очередь можно отменить.

## 2026-09-26

- Исправлен пропущенный импорт json в общем клиенте модели; добавлены проверки
  полного разбора потокового ответа для оценки вакансий и подготовки резюме.

- Главный список содержит только текущий поиск: пуст при открытии и очищается
  при новом запуске. Прошлые результаты остаются в истории.

- Обновлён интерфейс: светлая рабочая область, зелёная боковая панель,
  обзор с карточкой вакансии и счётчиками, фильтрация результатов без перезапуска поиска.
- Настройки и журнал разнесены по разделам; cookies скрываются по умолчанию.
- Добавлены проверки сохранности настроек и работы интерфейса с событиями поиска.

- Исправлен запуск в Python без keyring: предупреждение вместо закрытия приложения,
  недоступные cookies сохраняются при изменении остальных настроек.
- Добавлен start.cmd для запуска через окружение проекта.

- Исправлены ложные отказы для дневного сменного графика и отрицания вахты.
- Добавлена обработка JSON-LD массивов, графов и разных кавычек HTML.
- Описания больше не обрезаются; отсутствие текста выделяется в отдельный статус.
- Учёт вакансий перенесён в SQLite с версиями профиля, правил и моделей.
- Ошибки оценки повторяются при следующем запуске поиска.
- Настройки и top.md записываются атомарно; top.md обновляется во время работы.
- Cookies сохраняются в системном хранилище, исходный файл сохраняется при сбое переноса.
- Объединён клиент модели, добавлена проверка структуры вердикта.
- Навыки и курсы резюме ограничены исходными фактами, рядом с PDF сохраняется сравнение.
- Добавлены тесты, зависимости и обезличенные примеры; личные файлы исключены из Git.
